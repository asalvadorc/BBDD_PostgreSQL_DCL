# 9. Práctica: Copias de seguridad y restauración en PostgreSQL

## Objetivo

En esta práctica aprenderás a:

- Realizar copias de seguridad en PostgreSQL  
- Restaurar bases de datos a partir de backups  
- Trabajar con herramientas como **pg_dump**, **psql** y **pg_restore**  
- Utilizar PostgreSQL en un entorno con **Docker**  

---

## Enunciado

La empresa **TechShop** necesita asegurar la información de su base de datos `tienda`.  

Como administrador/a de bases de datos, deberás:

- Crear copias de seguridad  
- Simular la pérdida de datos  
- Restaurar la información  

---

## Parte 1. Preparación del entorno

1. Crear una carpeta llamada `backups` en la misma ubicación donde está el archivo docker-compose.yml, ya que será desde ahí donde ejecutaremos los comandos de Docker.

2. Comprobar que las herramientas `pg_dump` y `pg_restore` están disponibles en el contenedor.

    docker compose exec postgres pg_dump --version
    docker compose exec postgres pg_restore --version


---

## Parte 2. Backup en formato SQL

Realiza una copia de seguridad de la base de datos `tienda` en formato SQL.


    docker compose exec -T postgres pg_dump -U admin -C tienda > backups/tienda.sql


---

## Parte 3. Simulación de fallo

Elimina la base de datos `tienda`.


    docker compose exec postgres psql -U admin -d postgres -c "DROP DATABASE tienda;"


---

## Parte 4. Restauración con psql

Restaura la base de datos utilizando el archivo SQL generado.

En Linux:


    docker compose exec -T postgres psql -U admin -d postgres < backups/tienda.sql


En Windows:


    type backups/tienda.sql | docker compose exec -T postgres psql -U admin -d postgres


---

## Parte 5. Backup en formato dump

Realiza una copia de seguridad en formato binario (custom).


    docker compose exec -T postgres pg_dump -U admin -Fc -C tienda -f /tmp/tienda.dump


Copia el archivo al sistema anfitrión:


    docker cp postgres:/tmp/tienda.dump backups/tienda.dump


---

## Parte 6. Restauración con pg_restore

1. Elimina de nuevo la base de datos `tienda`.


    docker compose exec postgres psql -U admin -d postgres -c "DROP DATABASE tienda;"


2. Restaura la base de datos utilizando el archivo dump.


    docker compose exec postgres pg_restore -U admin -C -d postgres /tmp/tienda.dump


---

## Parte 7. Verificación

Comprueba el contenido de las tablas tras la restauración.


    SELECT * FROM app.productos;
    SELECT * FROM app.ventas;


---

## Parte 8. Cuestiones

Responde a las siguientes preguntas:

1. ¿Qué diferencia hay entre un backup en formato SQL y en formato dump?  
2. ¿Qué herramienta se utiliza para restaurar cada uno?  
3. ¿Por qué se utiliza la base de datos `postgres` durante la restauración?  
4. ¿Qué ocurre si intentas restaurar una base de datos que ya existe?  
5. ¿Qué ventajas tiene el formato dump frente al SQL?  

---

## Parte 9. Ampliación (opcional)

Realiza una copia de seguridad únicamente de la tabla `productos`.


    docker compose exec postgres pg_dump -U admin -t app.productos tienda > backups/productos.sql
